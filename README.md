# Christmas2026

RSVP website for the University of Auckland Department of Pharmacology and Clinical Pharmacology End of Year function on 9 December 2026.

## Deployment
This is a static single-page site. Import this repository into Vercel with the project root set to the repository root; no build command is required.

## Important
The current RSVP prototype stores submissions in the visitor's browser (localStorage). It is suitable for preview/testing only until a shared backend is connected. Do not rely on the organiser dashboard as a central RSVP database yet.

Production environment configured for cloud RSVP deployment.
